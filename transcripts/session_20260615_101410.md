## 转向函数总览

项目是 **阿克曼（Ackermann）转向底盘**，基于 STM32H743 + micro-ROS，转向函数分布在三个层级：

---

### 一、CAN 通信层 — `can_steer.c` / `can_steer.h`

负责与 EPS（电动助力转向）执行器通过 FDCAN 通信：

| 函数 | 作用 |
|---|---|
| `EpsSteer_SendTargetAngle(int16_t road_wheel_deg)` | 下发**车轮目标转角**（度），内部乘以减速比 12.0 换算为 EPS 执行器角度，通过 CAN ID `0x314` 大端发送 |
| `EpsSteer_SetManualMode()` | 发送全零帧，将 EPS 切换到**手动模式**（允许 MCU 下发角度命令） |
| `EpsSteer_SetZero()` | 将前轮转角归零（回正），内部调用 `SendTargetAngle(0)` |
| `EpsSteer_ParseFeedback(const uint8_t data[8])` | 从 EPS 反馈帧 `0x18F` 解析**实际车轮转角**（度），大端 int16 → 除以减速比 12.0 |

**关键常量**：
- `EPS_STEERING_RATIO = 12.0` — EPS 执行器角度 / 车轮转角减速比
- `EPS_CMD_ID = 0x314` — 控制命令帧 ID
- `EPS_FEEDBACK_ID = 0x18F` — 反馈帧 ID

---

### 二、底盘解算层 — `chassis_control.c` / `chassis_control.h`

负责 ROS2 `/cmd_vel` → 阿克曼目标量的换算：

| 函数 | 作用 |
|---|---|
| `Ackermann_Calc(linear_x, angular_z, out)` | **核心阿克曼解算**：δ = atan(L × ω / v)，将线速度+角速度换算为后驱目标速度 + 前轮转向角 |
| `Chassis_ControlFromCmdVel(linear_x, angular_z)` | 一站式接口：调用 `Ackermann_Calc` → `DriveMotor_SetSpeed` + `SteerMotor_SetAngle` |
| `SteerMotor_SetAngle(float angle_deg)` | 设置前轮目标转向角，限幅后调用 `EpsSteer_SendTargetAngle` 下发 CAN |
| `Chassis_CalcActualYawRate(linear_x_mps, steer_angle_deg)` | **反向解算**：根据实际车速 + 实际转向角 → 实际横摆角速度 ω = v × tan(δ) / L |

**关键参数**：
- `CHASSIS_WHEEL_BASE_M = 0.660` — 轴距 L
- `CHASSIS_MAX_STEER_ANGLE_DEG = 30.0` — 最大转向角 ±30°
- `CHASSIS_STEER_DIRECTION_SIGN = -1.0` — 方向取反（ROS 坐标系 vs EPS 协议方向）

---

### 三、FreeRTOS 任务调度层 — `freertos.c`

| 函数 | 作用 |
|---|---|
| `cmd_vel_callback()` | micro-ROS 订阅回调，收到 `/cmd_vel` 后更新 `g_chassis_cmd_linear_x` 和 `g_chassis_cmd_angular_z` |
| `StartControlTask()` | **10ms 控制循环**：超时 500ms 自动清零 → `Chassis_ControlFromCmdVel()` → 周期下发 |
| `can_rx_process()` | CAN 接收分发：`0x18F` → `EpsSteer_ParseFeedback` 解析实际转角 → `Chassis_CalcActualYawRate` 解算横摆角速度 |
| `HAL_FDCAN_RxFifo0Callback()` | FDCAN 中断回调：读取 CAN 帧 → 放入 `canRxQueue` → `canTask` 消费 |

---

### 数据流向图

```
ROS2 /cmd_vel (linear.x, angular.z)
    │
    ▼
cmd_vel_callback()  →  g_chassis_cmd_linear_x / g_chassis_cmd_angular_z
    │
    ▼  (10ms controlTask)
Chassis_ControlFromCmdVel()
    │
    ├─► Ackermann_Calc()  →  δ = atan(L·ω/v), 限幅 ±30°
    │        │
    │        ├─► DriveMotor_SetSpeed()  →  CAN 0x206
    │        └─► SteerMotor_SetAngle()  →  EpsSteer_SendTargetAngle()  →  CAN 0x314
    │
    ▼  (CAN 反馈)
EPS 0x18F 反馈帧
    │
    ▼
EpsSteer_ParseFeedback()  →  实际车轮转角 (度)
    │
    ▼
Chassis_CalcActualYawRate()  →  实际横摆角速度 (rad/s)  →  /odom 发布
```
